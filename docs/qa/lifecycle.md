# Renderer lifecycle QA

Date: 2026-09-13

Candidate base: `d669348`

Local preview: `http://127.0.0.1:4193/`

## Finding

`BETA-003` was reproduced before the fix in Chromium and Playwright WebKit with the browser's real `WEBGL_lose_context` extension:

1. Open the builder's 3D view.
2. Switch to 2D, which parks the 3D scene for reuse (`active=false`, scene and canvas retained).
3. Lose the WebGL context while the canvas is parked.
4. Switch back to 3D.

Before the fix, re-entry reported `active=true` but reused the same connected canvas with `gl.isContextLost()===true`. Three.js did not throw. That is a deterministic permanently blank renderer, and the app showed no recovery state.

The context-loss handler returned early whenever the viewer was inactive. It now treats a parked scene as owned renderer state: any loss event from the retained renderer exits and disposes the scene. The next 3D entry allocates one new live renderer. Context loss while 3D is active continues to exit with the existing safe recovery message.

This finding is separate from `BETA-001`, the native Safari blank observed after Help. A pre-fix Help probe showed that closing Help does not issue a demand render, but Chromium, Playwright WebKit, and a later native Safari 27 probe all preserved the canvas through Help. That render-count observation alone did not reproduce a visual failure, so this change does not add speculative continuous or Help-specific rendering.

## Automated coverage

`tests/qa-render-lifecycle.spec.mjs` covers:

- real context loss while a renderer is parked, followed by live-context re-entry;
- active context loss, safe exit, and retry with one replacement canvas;
- 120 Help, menu, play/pause, visibility, resize, seek, and 2D/3D transitions, including four parked-context losses;
- cancellation of a real delayed actor-image request without stale renderer attachment.

## Standalone soak

Run a local server on port 4193, then:

```sh
PREVIEW_URL=http://127.0.0.1:4193/index.html \
QA_LIFECYCLE_ITERATIONS=200 \
node tools/qa-lifecycle-soak.mjs
```
