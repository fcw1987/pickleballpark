## Visual and interaction direction

Original game panels and compact court context; readable live text for settings and descriptions; existing original display face for short headings only. Deliberate coordinated world surfaces and landmarks, preserved athletes/ball, contextual detail groups and actionable validation. Advanced editing remains available at every supported size.

Apple's [handheld game interface guidance](https://developer.apple.com/videos/play/meet-with-apple/243/) informs adaptive edge-anchored controls, safe areas, legible text and comfortable touch targets. Its guidance favors scrolling detail over shrinking text. Apple's [advanced game design session](https://developer.apple.com/videos/play/wwdc2024/10085/) likewise emphasizes adaptable layouts and 44-point default touch targets. These inform behavior; no system aesthetic, native status or certification is claimed. Existing locally generated font rights remain unchanged.
